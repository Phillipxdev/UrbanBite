# UrbanBite 🍔

UrbanBite is a responsive restaurant e-commerce website
built with HTML, CSS and JavaScript.

## Features

- Responsive design
- Product categories
- Shopping cart
- User registration and login
- Checkout system
- Admin dashboard
- Product management
- Order management
- LocalStorage
- DOM manipulation

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Git & GitHub

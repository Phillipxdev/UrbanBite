# 🍔 UrbanBite — Restaurant E-Commerce Website

UrbanBite is a responsive restaurant e-commerce web application built with **HTML5, CSS3, and JavaScript**.

The project demonstrates practical Front-End Development skills including responsive design, DOM manipulation, authentication logic, shopping-cart functionality, LocalStorage, checkout functionality, and an admin dashboard.

## 🚀 Features

### Customer Website
- Responsive and mobile-first design
- Food product categories
- Product search and filtering
- Dynamic shopping cart
- Add and remove cart items
- Cart quantity management
- User registration and login
- Checkout system
- LocalStorage data persistence
- Responsive navigation
- Interactive UI using JavaScript

### 🛠️ Admin Dashboard
- Admin dashboard interface
- Product management
- Add, edit and view products
- Order management
- Customer management
- Store navigation
- Responsive admin layout
